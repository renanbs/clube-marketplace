# /help

Displays available commands and harness utilities:

```bash
./bin/clube-config help
```

## Available Commands
- `/init` — Initialize project `AGENTS.md` and sync harness pointers.
- `/sync-harness` — Sync `@AGENTS.md` pointers for `CLAUDE.md`, `GEMINI.md`, `.cursorrules`.
- `/check-status` — Audit active harness alignment and instructions integrity.
- `/help` — Show help and command overview.
